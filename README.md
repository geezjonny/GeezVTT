# GeezVTT

A table-top VTT with **OBR's simplicity** (drop a map or token in and everyone sees it) and **GeezSheets' control**
(lights, doors, walls and traps are easy for the GM to run).

Status: just started. Code is borrowed from `../GeezSheets` (`js/vtt/`, `js/rodeo/`, `battlemap/`) as needed.

## Goals
- Drop-in simplicity: drag a map, token or image onto the table and it appears for all players instantly.
- GM control: walls, doors, lights and traps editable and toggleable live; dd2vtt import.
- Players join with a link (no install); `companion.html`-style sheets stay in GeezSheets.

## Non-goals (for now)
- Replacing GeezSheets (character sheets, level-up, Gaia data).
- Owlbear extension work; see `../GeezSheets/docs/obr-bridge-plan.md` for the fallback plan.
